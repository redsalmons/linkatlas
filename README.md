<h1 align="center">LinkAtlas</h1>

<h2 align="center">Know who your device is talking to.</h2>

LinkAtlas is a privacy auditing tool for iOS and Android. It shows every
remote endpoint your device connects to — IP, port, domain, byte counts and
timestamps — on a live connection map, so you can see what your apps are
actually doing on the network.

## What it does

- **Connection map** — live list of connections with remote endpoints,
  protocols, byte counters and timestamps, grouped per app flow
- **Metadata only** — the on-device tunnel (built on lwIP) inspects handshake
  metadata: IP, port, TLS SNI / DNS-derived names, byte counts, timing.
  Payloads are forwarded untouched and never inspected or stored
- **In-memory records** — connection records live in RAM only and are
  discarded. They are never written to disk and never leave the device
- **Optional lookup** — tapping an endpoint sends *only that single domain/IP*
  to our lookup service for an explanation (who owns it, what service it is,
  where it is hosted). No connection records are uploaded
- **Whitelist** — a downloadable domain/IP whitelist marks known-safe
  endpoints so you can focus on the unexpected ones

## Security model

The app talks to the lookup service over mutual TLS with a private CA,
using a three-tier certificate model:

| Identity | Where it lives | What it can do |
|---|---|---|
| Bootstrap certificate | Bundled in the app | `challenge`, `register`, `refresh`, `whitelist` only |
| Device certificate | Issued after registration | All API endpoints |
| Admin certificate | Out-of-band | Management console only |

- Device keys are generated on-device and never leave the
  Secure Enclave (iOS) / Android Keystore (StrongBox when available)
- Registration is gated by App Attest (iOS) / Play Integrity (Android)
- Connections without a CA-signed certificate are rejected during the
  TLS handshake, before any HTTP is exchanged
- Purchase verification goes through App Store / Google Play receipts
  validated server-side

The lookup **server implementation is closed source**; this repository is the
complete client so that the claims above can be audited end to end.

## Privacy

- No accounts, no analytics, no third-party SDKs with tracking
- Nothing is uploaded except an explicitly requested lookup address,
  purchase receipts, and one-time device registration data
  (platform, app version, device public key, attestation)
- In-app privacy policy (English, 简体, 繁體) ships inside the app and is
  shown before any network use

## Platforms

- **iOS** — SwiftUI app + PacketTunnel extension, Xcode project generated by
  [XcodeGen](https://github.com/yonsm/XcodeGen) (`xcodegen generate`)
- **Android** — Kotlin + Jetpack Compose + VpnService,
  `core/` shared C++ analyzer via NDK
- Shared C++ core (`core/`) — lwIP-based tunnel and DPI analyzer used by
  both platforms
